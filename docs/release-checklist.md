## 高德配置、配额与域名

- [ ] 仅在生产云函数环境变量中配置 `AMAP_WEB_KEY`，不写入仓库、小程序代码、构建产物或日志。
- [ ] 配置 `AMAP_ROUTE_QPS`，其数值不高于生产 Key 实际路线 API 配额，并保留限流余量。
- [ ] 在高德控制台核对 Web 服务 Key 类型、绑定应用、日配额、QPS 和告警；以真实云函数压测确认发起速率不超额。
- [ ] 确认仅云函数访问 `https://restapi.amap.com`；如 CloudBase 环境启用出站白名单，已添加该域名。
- [ ] 审核微信小程序 request 合法域名和 CloudBase 环境绑定，客户端不直连高德。
